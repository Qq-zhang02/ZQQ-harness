## 4. 踩坑记录（接力者必读）

1. **npm test 是显式文件清单**（package.json 逐个列 .test.ts）——新增测试文件必须同步登记，否则静默不跑。
2. **杀测试服务器用精确 PID**（`netstat -ano | findstr :端口` → `cmd //c "taskkill /F /PID <pid>"`）。Git Bash 里直接 `taskkill /F /PID` 会被路径改写（`/F`→`F:/`）报「无效参数」，必须套 `cmd //c`；绝不要 `taskkill /IM node.exe`（误杀全机 node）。
3. **server.ts 有 ≤250 行双哨兵**（contract.test.ts 一个 + smoke:sa4 一个，都按 `split("\n").length` 计数含末尾空串）——给它加行时同步收紧注释或把常量放别处（本次 SSE_PING_MS 放 core/http.ts 就是为此）。
4. **提示词插值注意字符串形态**：双引号串用 `"…" + CONST + "…"` 拼接；**模板字面量（反引号）内必须用 `${CONST}`**——批量替换时先看清目标行是哪种，反引号里塞 `" + CONST + "` 会变成字面文本（阶段 C 踩过，靠 typecheck 前的 grep 自查发现）。
5. 改 sections.ts/agent-task.ts 提示词后**先跑 contract.test.ts 的 golden**——渲染文本有意变更时更新快照 = 显式决定；插值化设计目标就是 golden 零改动。
6. **contract.test.ts 哨兵扫描排除 .test.ts**（listTsFiles 过滤）——测试文件里的字面量不算违反单一出处。
7. 活服务器冒烟模板：`USERPROFILE=$(临时目录) ZQQ_NO_BROWSER=1 PORT=18787 node src/web/server.ts`（隔离真实用户数据；验证 harness.json 覆盖时可先往临时目录写 `~/.ZQQ-harness/harness.json` 再起服，再用 `node --input-type=module -e 'const c = await import("./src/config.ts"); c.initConfig(); console.log(c.XXX)'` 读生效常量——**D2 起必须先 initConfig()**，直接 import 读到的是纯缺省〔这是机制不是 bug：测试/直调入口不受真机 harness.json 感染〕，不必起服）。
8. Git Bash 下 git 的 LF→CRLF warning 无害；curl 输出中文乱码只是控制台显示问题（用 python -c json.load 校验即可）。
9. docs/21 头部实施记录块按时间顺序追加（A → B → C → D…），「—— 完 ——」标记始终在最末。
