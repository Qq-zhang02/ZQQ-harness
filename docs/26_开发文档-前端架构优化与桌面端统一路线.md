## 2. 核心决策：「无构建」≠「单文件」

docs/21 §5-6 不变量的实质是**禁止 node_modules 构建链**（含前端 npm 依赖）。而三个**零构建能力**是现成的：

1. **浏览器原生 ES Modules**：`<script type="module" src="/app/main.js">` 同源加载、原生 import——无需打包器；module 默认 defer，与现状"脚本置于 body 尾部"时序等价；
2. **Node 原生 import .js**：node:test 直接 `import("./replay.js")`——前端逻辑**首次可单测**（登记 package.json 显式测试清单即可，.js 也能进 `node --test`）；
3. **tsc 的 checkJs**：JSDoc 注释即类型，`tsconfig.frontend.json`（allowJs + checkJs + DOM lib）单独跑——拿到 ~80% 的 TS 价值，零构建。

因此 F 线的形态是：**纯逻辑进 `src/web/public/app/*.js`（可测模块），视图层暂留 index.html（F4 再拆）**。不变量的正式修订（"无构建单文件" → "无构建：原生 ES Modules，禁止 node_modules 构建链与前端 npm 依赖"）在 **F4 实施时**才做——F1–F3 期间 index.html 仍是可独立运行的单文件（只是 import 了同目录模块），README 无需中途改口。

## 3. F1：纯逻辑抽离——可测化（最高收益，~1.5 天）

### 3.1 模块清单（首批三个，全部无 DOM 纯函数）

```
src/web/public/app/
├── replay.js        竞态决策（痛点 1 的 150 行）：
│                    ├─ decideRoute(evName, d, { viewId, loading }) → "render"|"state"|"usage"|"turnEnd"|"buffer"
│                    │   （route() 的分支判定数据化；渲染动作留在调用方）
│                    ├─ filterByMl(buf, snapshotLen) → items（switchSession 的缓冲重放过滤，
│                    │   L1942 的 splice+filter 纯函数化）
│                    └─ decideFollow(d, { viewId, viewSeqSeen, switchingTo }) →
│                        { type: "follow"|"defer"|"ignore", id?, seq? }
│                        （sessions 事件的乒乓防护决策，SSE_HANDLERS.sessions 内嵌逻辑抽出）
├── turns.js         轮分组与折叠决策（foldTurns 的数据版）：
│                    ├─ groupTurns(messages) → turns[]（user 气泡切分的轮结构）
│                    └─ decideFold(turn) → 可折叠键集（"哪些块收进执行过程"的决策；
│                        DOM 搬运留在视图层——foldTurns 保留但变薄）
├── autoreport.js    自动送达解析：splitAutoText(text, { reportPrefix, statusPrefix }) →
│                    { kind, body }、autoReportSummary(text) → 摘要行、firstLine/prettyArgs/fmtTok/fmtDur
│                    （前缀作参数传入——meta 下发的协议契约不变）
└── *.test.js        node:test 直接 import；每模块 8–12 用例（切走切回/乒乓/过期快照/
                     缓冲重放/轮折叠边界/前缀穷举）
```

**迁移方式**：index.html 的 `<script>` 改为 `<script type="module">`（"use strict" 隐式），在头部 `import { decideRoute, … } from "/app/replay.js"` 等三行——**只有 ~150 行决策逻辑外移，其余 2,100+ 行原地不动**（`el`/`esc`/`mdLite` 等 DOM 工具留到 F4 再动，避免一次触碰 34 处 innerHTML 调用点）。

### 3.2 配套三件事

1. **静态服务做成模块**（`modules/web-static/`，组合清单加一行——模块化架构扩展点的示范，server.ts 瘦壳与 ≤250 行哨兵零触碰）：setup 时 `readdirSync` 枚举 `public/app/*.js`，**逐文件精确注册** `/app/<name>` 路由（Registry 是精确匹配无通配；响应 `text/javascript; charset=utf-8` + `Cache-Control: no-cache`（与 index.html 同款，改完刷新即生效）；路径 resolve 后必须仍以 app 目录为前缀（禁穿越））。**取舍**：新增模块文件需重启服务才注册——开发摩擦可接受（改文件内容不需要，仅新增文件要）。
2. **类型检查独立配置**：新开 `tsconfig.frontend.json`（`allowJs` + `checkJs` + `lib: ["ES2023","DOM","DOM.Iterable"]` + `noEmit`，include 仅 `src/web/public/app/**/*`）；`typecheck` 脚本改 `tsc && tsc -p tsconfig.frontend.json`。**单独开文件的原因**：主 tsconfig 开 checkJs 会波及 scripts/*.mjs。
3. **哨兵联动**（痛点 5 全量清单，实施时以 `grep -rn "index.html" src scripts` 复核）：contract.test.ts 的 `SSE_HANDLERS` 锚点 / `dispatchBuffered` 锚点 / CFG 字面量哨兵 / docs/24 设置模态哨兵（若断言对象迁入 app/，改为扫描对应模块文件）；smoke-sa4.ts 两处源码断言同步。**新增哨兵**：`app/` 下禁止出现 `node_modules`/`https://` import（零依赖边界）+ 纯逻辑模块禁止 `document`/`window` 引用（可测性边界，静态 grep 断言即可）。

### 3.3 验收

`npm run typecheck`（两段式）过；`npm test` 新增 24–36 项全绿（.test.js 登记进 package.json 清单）；既有 402 项不回归；smoke-sa4 过；活服 GUI 冒烟（切走切回运行中会话、刷新恢复、自动送达气泡、轮收纳）零行为变化。

## 5. F3：渲染统一收官（= docs/23 D3 剩余项正式并入，长期渐进、独立可停）

- **重灌点清单与优先级**：`renderDrawerList`（抽屉列表，2s 轮询重灌——收益最大）→ `renderRecycle`（回收站）→ `renderProvList`（提供方列表）→ `renderHistory`（历史快照整体重建；因每次都是全量新数据且低频，**keyed 化收益中等，放最后或豁免**）→ `makeTimeline`（增量追加为主，豁免）。
- **做法**：照搬 D3 首块样板——每个渲染函数拆 make（建骨架+建时绑定一次事件，经节点 `_key`/dataset 读最新数据）/ update（刷新态），列表用 `reconcileKeyed`；新代码一律 createElement（`el` 不带第三参）。
- **补丁退役**：重灌点消失一个就退役对应的滚动/展开保持补丁（`rebuildKeepScroll`/`harvestOpenKeys`/`keepOpenOf`），最终三者全删。
- docs/23 的 D3 接力使命由本节接管；README「当前进行中」已同步改指本文档。

**验收**：每点迁移后该区域手工冒烟（滚动位置/展开冻结/两步确认 armed 态不被刷新打断）+ smoke-sa4 源码断言不回归。

## 8. 与桌面端的统一编排（本文档核心）

### 8.1 依赖图

```
DT0 服务端就绪化 ──→ DT1 壳落地 ──→ DT2 打包分发 ──┬→ DT3 桌面增强（通知项依赖 F1）
（docs/25 §5）                                    └→ （托盘/自启无前端依赖，随时可做）
F1 纯逻辑抽离 ──→ F2 store 化 ──→ （F3 长期渐进，任意时点插入；F4 条件触发）
     │
     └─ web-static 模块（/app/*.js 静态服务）──→ DT2 打包验收须含"app/*.js 加载"检查项
```

**硬依赖只有两条**：① DT2 的产物校验清单加一条"打包版加载 `/app/<模块>.js` 成功"（若 F1 已落地；electron-builder files 已含 `src/**/*`，app/ 自动进包，验的是事实而非配置）；② DT3 的"审批通知"是**前端** Notification 功能（`http://127.0.0.1` 是 secure context，渲染进程直接可用，零壳代码），排在 F1 之后做（落在模块化前端上）。其余全部可独立推进。

### 8.2 四梯队建议顺序（单人串行的现实编排）

| 梯队 | 内容 | 工时 | 出口验收门 |
|---|---|---|---|
| ① 地基 | **DT0**（半天，docs/25 §5）→ **F1**（1.5 天，§3） | ~2 天 | DT0 三项验收 + F1 新增测试全绿 |
| ② 桌面形态 | **DT1 壳落地**（1 天）→ **DT2 打包**（1 天，验收含 app/ 加载检查） | ~2 天 | 干净环境安装→全流程冒烟通过 |
| ③ 质量（长期渐进） | **F2**（1 天）→ **F3** 逐点（每点独立可停） | 弹性 | 每区/每点独立验收 + 全量回归 |
| ④ 增强/条件 | **DT3**（通知依赖 F1；托盘/自启独立）与 **F4**（条件触发） | 按需 | 各自验收 |

**串行原则**：任何时刻只动一条线；前端大改（F1/F4）与打包发布（DT2）**错开**，打包前跑全量冒烟（`npm test` + smoke 系列 + 手工清单）；每阶段独立 commit、独立补实施记录。

### 8.3 共享基建与零漂移重申

- **web-static 模块两线共用**：浏览器直开与桌面渲染进程加载的是同一份 `/app/*.js`；
- **双入口零漂移**（docs/25 §8-2 重申）：`npm run web` 与桌面壳跑同一份 server.ts 与同一份前端——任何"只给桌面"的行为分支先问能否做成两端共享的服务端/前端能力；
- 前端改动的哨兵联动（§3.2-3）对两线同等生效。

## 9. 统一维护纪律与不变量（F 线 + DT 线合并，任何改动不得破坏）

1. **壳不进业务**（docs/25 §8-1）：desktop/ ≤2 文件、主进程不 import `src/**`、不读写业务数据文件。
2. **双入口零漂移**（docs/25 §8-2 + §8.3）：浏览器与桌面同一份代码；DT0 的 127.0.0.1 默认绑定是唯一声明的行为变化。
3. **Electron 升级核对单**（docs/25 §8-3）：内置 Node ≥22.18（type-stripping）→ 干净机冒烟 → builder 兼容。
4. **壳不进 `npm test`**（docs/25 §8-4）：GUI 用打包后手工清单 + 零 token 桩。
5. **（F 新增）app/ 零依赖**：禁止 import node_modules 与任何 `https://` 远端模块（哨兵锁定）；模块间 import 一律相对路径。
6. **（F 新增）纯逻辑模块禁 DOM**：replay/turns/autoreport/store 不得引用 `document`/`window`（可测性边界，静态断言）；需要 DOM 的代码属于视图层（F4 前留在 index.html）。
7. **（F 新增）行数防回涨**：F1 完成后设 index.html 内联 script 行数上限哨兵（当时实测值 +10% 取整），防止新功能又堆回单作用域。
8. **（惯例）**：新增 .test.js 须登记 package.json 显式清单（docs/22 踩坑记录）；每阶段 typecheck + 全量测试 + 手工冒烟；实施记录写本文档头部。
